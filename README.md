# Dotfiles

## Usage

Either create manual symbolic links or manage it automatically with stow

```
stow .
```

## Niri

The niri config is a set of overrides for the stock CachyOS configurations, rather than a full configuration. See the base in the CachyOS repository [here](https://github.com/CachyOS/cachyos-niri-noctalia).

## Noctalia

Many configurations rely on noctalia creating a particular theme file. If not using noctalia, simply remove these and theme manually.
